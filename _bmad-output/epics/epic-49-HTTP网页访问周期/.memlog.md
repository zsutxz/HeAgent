- (constraint) Epic 49 继承项目既有 asyncio、Pydantic、CLI/wiring 组合根和 Engine 治理链；HTTP 入口不得改变 AgentLoop、Provider、Engine、ToolRegistry 的职责边界。
- (constraint) 继承 Epic 48 的网络入口原则：network 层只负责传输、协议和生命周期；入口层注入 handler；默认 loopback；非 loopback 必须显式警告，且无认证、无 TLS 不是生产安全边界。
- (decision) HTTP 采用轻量 ASGI 栈，首选 Starlette + Uvicorn；Starlette 负责路由、StreamingResponse 和静态资源，Uvicorn 负责 asyncio 服务器生命周期；HTTP 依赖放入可选 extra，缺失时显式失败。
- (decision) HTTP 传输层与 Agent 组合根分离：network/http_server.py 只接收已注入的 session/run service 协议，不导入 cli、wiring、agent、provider 或 engine；cli_http.py 负责 Settings、Provider/Engine/Memory 组装和 handler 注入。
- (decision) HTTP MVP 维护单进程单用户 session，session 状态由 HTTP application/service owner 持有；每个 run 创建独立 AgentLoop，run task、事件缓冲和状态互不共享可变对象。
- (decision) HTTP API 统一使用 /api 前缀和 Pydantic 请求/响应模型；健康检查为 GET /api/health，session 为 GET /api/session，run 创建为 POST /api/runs，SSE 为 GET /api/runs/{run_id}/events，取消为 DELETE /api/runs/{run_id}。
- (decision) SSE 是只读订阅，不拥有 run task；客户端断线只释放订阅资源，不取消 Agent run；取消只能通过 DELETE 显式触发。事件使用单调递增 id，Last-Event-ID 从进程内 ring buffer 恢复，超出窗口必须返回明确 resync 错误。
- (decision) HTTP 服务生命周期由显式 start/serve/close 管理；启动绑定失败、非法配置和关闭 drain 超时均显式失败或告警，不静默降级；close 必须有硬上界并回收/登记残留 run 与订阅任务。
- (decision) 默认绑定 127.0.0.1:8766；HTTP_HOST/HTTP_PORT 等配置由 Pydantic Settings 校验，CLI 子命令覆盖仅作用于本次实例，不回写全局 Settings；非 loopback 复用 network.exposure 的判定和警告。
- (decision) 安全响应由 HTTP 层统一加 CSP、X-Content-Type-Options: nosniff、frame 禁止等 headers；API 禁用宽泛 CORS，校验 Host/Origin 同源关系；提示词和 Agent 输出按纯文本传输，禁止未经安全处理的 HTML 注入。
- (decision) HTTP 请求体、prompt、连接数、in-flight run 数、事件缓冲、run/request/shutdown timeout 均有配置上限；超过上限返回稳定、脱敏的错误结构，不返回 traceback、密钥、绝对路径或 prompt/answer 内容。
- (decision) HTTP Agent handler 复用既有 AgentLoop/Engine 治理链，工具调用仍经过 PolicyEngine.evaluate → ToolExecutor → SafetyGuard.check → handler；HTTP 入口不自动连接 MCP，不实现 stdin 审批旁路。
- (decision) 静态 Web UI 与 API 同源由同一 ASGI app 提供；资源位于 src/heagent/web 并纳入 wheel；运行时通过 importlib.resources 或包资源 API 解析，禁止开发机绝对路径。
- (decision) 测试按层隔离：network/http_server 使用 fake service；HTTP 集成使用 StubProvider 和本地 ASGI/随机 loopback；静态资源和 wheel 内容单独验证；默认回归不依赖外部网络或真实凭据。
- (assumption) 当前 Python 3.11+ 项目允许新增 Starlette/Uvicorn 作为 HTTP 可选依赖；实际版本在实现前以当前锁定环境和包元数据验证。
- (question) 是否需要在 HTTP MVP 完成后把 session/run 状态持久化到现有 SessionStore/RunStore；当前 Epic 49 明确采用进程内状态，重启丢失。
